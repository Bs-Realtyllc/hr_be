# ServiceCredential.controller

**Status:** released (~100% complete)

## What it does
The controller handles CRUD operations for service credentials related to employees.

## Where it lives in the UI
- Backend API route: GET `/employees/:employeeId/serviceCredentials`
- Backend API route: POST `/employees/:employeeId/serviceCredentials`

## Known limitations / in-progress
- No user interface screens are directly consumed by this API.
- The API is only available for backend operations.
