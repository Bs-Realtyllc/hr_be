# Feedback Controller

**Status:** released (~100% complete)
**Last updated:** 2026-09-19 — from commit d0bb07b

## What it does
This controller handles CRUD operations for feedback data, including listing, creating, updating, and removing feedback entries. It also provides a summary of feedback records.

## Where it lives in the UI
- Backend API routes: `list`, `create`, `remove`, `summary`
- No actual UI screens.
