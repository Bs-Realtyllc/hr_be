# Leave Controller

**Status:** released (~100% complete, if known)
**Last updated:** 2026-09-14 — from commit 0748221

## What it does
This controller manages employee leave requests and approvals. It includes methods for listing, balancing, reporting, and managing leave records.

## Where it lives in the UI
- N/A (Backend API Route)

## Key flows
1. **List Leave Records**: Retrieve a list of leave records based on employee ID and status.
2. **Balances**: Retrieve leave balance information for an employee.
3. **Report**: Generate a report of leave records.
4. **Out Today**: Retrieve leave records for today.
5. **Out This Week**: Retrieve leave records for this week.
6. **Create Leave Request**: Create a new leave request via an API.
7. **Approve Leave Request**: Approve a leave request.
8. **Reject Leave Request**: Reject a leave request.
9. **Update Leave Request**: Update a leave request.
10. **Cancel Leave Request**: Cancel a leave request.
11. **Create Leave Request via Mail**: Create a new leave request via email.

No known limitations or in-progress work.
