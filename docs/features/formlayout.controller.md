# FormLayout

**Status:** released (~100%)

**Last updated:** 2026-09-19 — from commit d0bb07b

## What it does
This feature provides a controller for managing form layouts, including operations to get, set, upload, download, and delete contract templates.

## Where it lives in the UI
N/A — This feature is a backend API and does not have a corresponding screen in the UI.

## Key flows
1. **Get Form Layout**: Queries a form layout by type and returns the data.
2. **Set Form Layout**: Creates a new form layout by type and returns a success message.
3. **Upload Contract Template**: Saves a contract template file to the system.
4. **Download Contract Template**: Downloads a contract template file from the system.
5. **Delete Contract Template**: Removes a contract template from the system.

## Known limitations / in-progress
- No user-facing screens are associated with this API.
