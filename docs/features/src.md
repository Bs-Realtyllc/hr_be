## What it does
The `src` feature provides a comprehensive API for interacting with various services and resources. It includes endpoints for user authentication, data retrieval, and other operations.

## Where it lives in the UI
N/A

## Key flows
1. **User Authentication:** Navigate to the `/login` route to authenticate.
2. **Data Retrieval:** Use the `/data` API endpoint to fetch resource information.
3. **Resource Management:** Utilize the `/resources` API to manage and interact with resources.

## Known limitations / in-progress
- The `/data` endpoint is currently under development and not fully functional yet.
- The `/resources` API has a few pending changes and improvements that are in progress.
